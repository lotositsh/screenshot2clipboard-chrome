# screenshot2clipboard

A minimalist Chrome extension that takes a screenshot of the current tab and copies it directly to your clipboard — no need to save it to your disk or perform any extra steps. It also includes an option to upload screenshots to ibb.co (requires an API key).
## How it works

1. Click on the extension icon and the visible image is saved to the clipboard as a screenshot.

## Installation
open chrome://extensions/
Enable Developer mode
Load unpucked
